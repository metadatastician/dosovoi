# Lightweight mascot taxonomy

This taxonomy is an implementation index, not pseudo-biology and not a claim
about universal symbolism.

| ID | Prototype form | Functional association | Encodings | Posture vocabulary |
|---|---|---|---|---|
| `bunny` | Soft bunny-like outline | Quiet Serenity prototype | ASCII, Unicode, text | still, compact, warning-facing, resting, low-stimulation |
| `puff` | Cloud/puff outline | Detachment and rest prototype | ASCII, Unicode, text | still, compact, warning-facing, resting, low-stimulation |
| `lens` | Small tool-free attentive outline; identifier retained provisionally | Vigilance-reminder prototype | ASCII, Unicode, text | still, compact, warning-facing, resting, low-stimulation |

The association is descriptive, not binding: any mascot can render any mode.
Risk level is deliberately excluded because it belongs to the warning subsystem,
not mascot identity. Personality, rarity, mood, relationship status, ownership,
rewards, needs, and autonomous capability are also excluded.

New entries should have a stable identifier, restrained form description,
ASCII/Unicode/text equivalents, all supported static postures, cultural review
status, accessibility notes, and licence provenance.

The provisional `lens` identifier no longer describes the rendered object. The
prototype removed its lens/probe shape because it could imply inspection or
authority; a future compatibility-breaking naming review may replace the ID.
